## Elevator pitch (one paragraph)
Orvima is an open-source MCP server that hands AI agents real browser control —
clicks, typing, screenshots, OCR, video recognition, voice — without handing away
the keys. A built-in Sentinel safety gate classifies every action locally
(no network, no API keys) and asks a human only for the risky ones. Runs
entirely on `127.0.0.1`. MIT licensed.

## Logo concept
- **Symbol:** A shield with a stylized eye + cursor arrow. The shield = safety.
  The eye = vision/OCR. The arrow = click/action.
- **Wordmark:** "orvima" lowercase in a clean sans (e.g. Inter or Geist).
- **Palette (locked per project constraints):**
  - Background: `#0D1117` (dark)
  - Accent: `#F5A524` (amber) — primary CTA
  - Neutral text: `#E6EDF3`
  - Danger: `#F85149`
  - Success: `#3FB950`

## Mascot / avatar
A minimalist space-pioneer motif (Orvima = orbital vision on your machine).

abstract — no mascot, professional dev-tool look.
