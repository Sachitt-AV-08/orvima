The three things that actually matter

Live viewport

See exactly what the agent sees. Frames stream in real time over SSE, so you are never guessing what it is looking at.

Human in the loop

Pause or resume a run at any point. An optional fail-closed approval gate holds risky actions for a human before they fire.

Verified steps

Every action confirms the DOM result before the agent proceeds. No silent failures, no guessed success.
